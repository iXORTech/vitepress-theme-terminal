# Advanced

The index page of the **nested** `advanced/` folder.

Because this folder sits on the explorer's *second* layer, it starts
**collapsed** by default — you reached it either by clicking its label (which
opened this page and expanded the folder in one go) or via its chevron.

Your expand/collapse toggles are persisted: leave this folder open, reload the
page, and it stays open.

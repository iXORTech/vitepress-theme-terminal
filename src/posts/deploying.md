# Deploying Your Site

Because this is a standard VitePress theme, deployment is unchanged: build the
static site and host the output anywhere that serves files.

## Build once, host anywhere

Run the build, take the generated directory, and drop it on any static host or
CDN. The theme adds no server requirement of its own.

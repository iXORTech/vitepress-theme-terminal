# Markdown, Powered Up

Beyond standard markdown, the theme wires in a plugin suite — footnotes,
definition lists, subscripts, marks, math — plus admonition callouts and
card-style code blocks with a copy button.

## Localized content

An author can even provide per-language versions of a page's body; the rendered
content switches with the UI language, no URL change.
